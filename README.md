This repository holds the make.fun entry for the bounty `u-gudril-cool-one-sentence-one-journey-410686ca`: a small Python 3.13 program, standard library only and with no network access, that writes one short text — a complete story about a journey told in exactly one sentence — to the folder named by `MAKEFUN_OUTPUT_DIR` when that variable is set, or by `OUTPUT_DIR` when only that one is set, and to `/output` otherwise, creating the folder as needed, writing the bytes with no trailing newline and printing the character count to stderr.

The entry text, written verbatim to `entry.txt`:

```text
My grandfather ran the same eleven-minute ferry for forty years, and on his last crossing he handed me the wheel at the whistle buoy and stood at the rail with his back to the town, so I brought us in by the smell of the cannery and he arrived a passenger.
```

Run it with:

```console
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
